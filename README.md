## Описание 
Веб-сервис предназначен для автоматизированного сбора (агрегации), обработки и поиска новостных публикаций Вятского государственного университета

## Пайплайн обработки данных
На схеме представлен пайплайн получения, обработки и сохранения новостных данных

![Пайплайн](screens/pipeline.png)

Обновление данных выполняется фоновым модулем с периодичностью один раз в час

### Предобработка текстов
1. Токенизация
2. Лемматизация
3. Удаление стоп-слов (предлоги и союзы)

### Удаление информационного шума
Выполняется с помощью обученной модели логистической регрессии на векторах текстов TF-IDF

### Дедупликация новостных публикаций
Выполняется с помощью оценки косинусного сходства между векторами текстов TF-IDF

### Извлечение структурных подразделений
Выполняется методом сопоставления лемматизированных текстов с лемматизированными подразделениями из фиксированного списка
